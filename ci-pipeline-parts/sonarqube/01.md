## For a clean/normal Maven JaCoCo setup, configure JaCoCo so that:  
- **`mvn test` → runs tests + collects coverage data (`jacoco.exec`)**    
- **`mvn verify` → runs tests + generates the JaCoCo reports (`jacoco.xml`, HTML, CSV)**    

The key is to bind `prepare-agent` to the test lifecycle and `report` to `verify`.  

**Recommended `pom.xml`**
