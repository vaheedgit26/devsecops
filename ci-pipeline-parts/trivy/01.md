## 1. Trivy Installation
```yaml
- name: Install Trivy
  uses: aquasecurity/setup-trivy@v0.2.6
  with:
    version: latest
    cache: true

- name: Verify Trivy installation
  run: |
    trivy --version
    which trivy
```

## 2. Trivy Filesystem scan (Dependency Scan)
> *Scans for repository/files/dependencies/configs*
```yaml
- name: Trivy Filesystem Scan
  uses: aquasecurity/trivy-action@master
  with:
    scan-type: fs
    scan-ref: .
    format: sarif
    output: trivy-fs.sarif
    severity: HIGH,CRITICAL
    ignore-unfixed: true
    exit-code: 1

- name: Upload Trivy SARIF
  if: always()
  uses: github/codeql-action/upload-sarif@v4
  with:
    sarif_file: trivy-fs.sarif
    category: trivy-fs

- name: Upload Trivy filesystem report
  if: always()
  uses: actions/upload-artifact@v4
  with:
    name: trivy-filesystem-report
    path: trivy-fs.sarif
    retention-days: 2
```

## 3. Trivy Image Scan  
> *Scans for  packages/libraries inside image*
```yaml
- name: Trivy Image Scan
  uses: aquasecurity/trivy-action@<pinned-version>
  with:
    image-ref: my-app:123
    format: sarif
    output: trivy-image.sarif
    severity: HIGH,CRITICAL
    ignore-unfixed: true

- name: Upload Trivy Image SARIF
```
